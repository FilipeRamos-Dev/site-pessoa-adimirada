# Atividade 04 - Biografia 
> Nesta atividade, realizei através da Linguagem de Marcação HTML e da Linguagem de Estilização CSS para criar uma página web de uma biografia sobre uma pessoa a quem eu adimiro (Ayrton Senna da Silva).

## Conceitos trabalhados
Trabalhamos com conceitos como: 
- Conceitos de comportamento das tags, principalmente o comportamento de blocos;
- Linkar arquivo CSS com arquivo HTML;
- Estilizar em um arquivo CSS, sem estilizar dentro do arquivo HTML;
- Introdução a tags como "margin", "border" e afins.
